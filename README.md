# 📊 Stock Market Data Analysis

This repository contains learning materials and implementation files for basic stock market data analysis using Python and Pandas.


## 📖 Learning

The **learning** folder contains study notes and documentation related to:

- Pandas
- Supervised Machine Learning
- Unsupervised Machine Learning

These notes are created for learning and reference purposes.

## 💻 Implementation

The **implementation** folder contains the practical part of the project.

### Dataset
- `stocks.csv` – Stock market dataset used for analysis.

### Python Files
- `load_data.py` – Loads the dataset using Pandas.
- `analysis.py` – Performs basic data analysis.
- `visualization.py` – Creates simple charts for data visualization.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- CSV

## 🚀 How to Run

1. Clone the repository

```bash
git clone <repository-url>
```

2. Move to the project folder

```bash
cd Data-Project-04-Rajan
```

3. Install required libraries

```bash
pip install pandas matplotlib
```

4. Run the implementation

```bash
cd implementation
python load_data.py
```
